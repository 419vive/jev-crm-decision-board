# 名單決策看板（Jev × CRM）

廣告名單進 CRM 前，由 [TypeSafe Jev](https://typesafe.ai)（System One 決策模型）分成五級並附信心度：
優先撥／一般撥／需人看／反射填表／無效。模型只建議，撥不撥、怎麼撥由業務決定。

- 看板：GitHub Pages（本 repo 的 `index.html`）
- 資料：`data/demo.json` 為**合成示範資料**，無任何真實姓名、電話、Email
- 正式使用：由私有管線 `export_jev_board.py` 從 Jev 分級紀錄去識別化匯出後覆蓋同一檔

## 五個決策點
1. 名單進來 → 真買家／反射／無效，值不值得優先撥
2. 撥打之後 → 再撥／LINE 訊息／等活動提醒
3. 活動前 → 缺席風險與提醒強度
4. 活動後 → 熱／溫／冷／培養
5. 舊客再啟動 → 誰值得再發 EDM

分工鐵律：程式算數、模型判斷、人按鍵。
